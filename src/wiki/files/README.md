# Wiki hosted files

Put downloadable files for wiki pages in this folder.

## How to use

- Add files under a topic folder, for example src/wiki/files/magewell-pro-capture-hdmi.
- Link to them from wiki markdown with /wiki/files/... URLs.
- Rebuild to publish.

## Example

- /wiki/files/magewell-pro-capture-hdmi/magewell-pro-capture-hdmi-manual.pdf
- /wiki/files/magewell-pro-capture-hdmi/magewell-linux-driver.zip
